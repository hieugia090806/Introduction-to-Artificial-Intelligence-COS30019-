📚 B. Course & Assessments Overview
This repository contains a comprehensive body of work divided into four critical phases of the AI development lifecycle.
    1. Assignment 1: Fundamental AI Concepts
    Focuses on the foundational theories of Artificial Intelligence, including search space analysis and basic heuristic evaluations.
    
    2. Assignment 2A: Pathfinding & Search AlgorithmsImplementation and comparative analysis of various search strategies to solve route-finding problems.
        * Key Algorithms: DFS, BFS, UCS, GBFS, A*, and Beam Search.
        * Metrics: Evaluating performance based on Exploration Ratio and Nodes Expanded to identify the most efficient navigation strategy.
    
    3. Assignment 2B: Deep Learning & System IntegrationDevelopment of the TBRGS (Traffic-based Route Guidance System) — a technical bridge between AI training and real-time application.
        * AI Models: Training and fine-tuning LSTM, GRU, and Bi-LSTM architectures for traffic volume prediction.
        * Backend: A FastAPI infrastructure using a Singleton initialization strategy and Pydantic for schema validation.
        * Frontend: A responsive Vite + React dashboard for data visualization and route planning.
        * Performance: Achieved an $R^2$ score of 0.89 with the BLSTM model.
        
    4. Assignment 2C: Ethical Considerations (TBRGS+): An individual research report exploring the ethical implications of AI in society.
        * Scope: Identifying design decisions and technical choices that impact users and stakeholders.
        * TBRGS+ Extension: Analyzing a hypothetical mobile-based system that collects personal location data and user profiles.
        * Key Focus: Data privacy, algorithmic bias, and the balance between technical efficiency and user ethics.
